# Three kinds live here:
#   1. Public by design -- login/register/reset, health, signed
#      webhooks, token-bearer share links.
#   2. Guarded by something that is not authentication -- the
#      /setup/* routes authorize by network locality (loopback
#      client, local Host header), so any anonymous caller that can
#      reach loopback passes. Defensible for first-run setup, but it
#      is not identity, so it is listed rather than hidden.
#   3. Not yet fixed.
#
# The list must match the tree exactly: entries may be removed when a
# route gains auth, and adding one is a reviewable diff.
