All 68 reported DOM flows (four per alert) cross unrelated settings and request cache keys. CodeQL connects the TTS model setting to the Review screen's `tldw:lastMediaId`, then connects `/api/v1/media/{id}` to unrelated requests through the shared rate-limit map. The settings cache keys include the area and setting name. The request cache keys include path and request scope. These keys do not match. The two URL fixes address the actual response inputs, independently of the reported dataflow.

The WebUI's `@plasmohq/storage` shim separately persists the provider settings through the primary `Storage.set` path. Its local area uses `window.localStorage` and JSON serialization. The mirror trace in 2723 does not describe that path, and this review does not establish a safe credential storage policy for it. Any migration away from that storage needs to preserve working search and TTS settings. The clip handoff fingerprint is deterministic account metadata, though the traced path does not persist the raw key.

All 415 tests in those five suites passed on Node 20. Another 76 tests passed for the shared URL/image guards, browser object URLs and download behavior, and 97 passed for Audio Studio and workspace diagnostics.
