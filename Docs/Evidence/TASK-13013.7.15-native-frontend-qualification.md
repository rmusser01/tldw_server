resolution instead of Next's actual dependency context, and root-owned Grype
cache inaccessible to host hashing. Commit0463dd5841 corrected these with a
redacted per-invocation fixture, createRequire from Next's image optimizer, and
runner-owned Grype cache/private writable tmpfs. No auth or scan check was bypassed.

clean exit only to the stub. A real Docker regression failed first with the
unchanged ten-second timeout, then passed two health/negative-route/shutdown
cycles. Local emulation established fixture behavior only; the final native run
above supplies actual application qualification.
