## Verification procedure and retention

All signature checks used the existing verification image
`sha256:9803426ce3cc2b0b9938db476ed1b296088ad85fed8419b02dcf3aef5a94186d`,
GnuPG 2.4.7/libgcrypt 1.11.0. Containers used `--pull=never`, `--network none`,
read-only root and inputs, UID/GID 1000:1000, no capabilities, no-new-privileges,
64 PIDs, 256 MiB memory, one CPU and a disposable 16 MiB `/tmp`. Execution was
amd64 emulation on arm64; no native performance qualification follows.

The core commands inside each disposable container were:

```sh
# Ubuntu: fresh private keyring, then verify the retained descriptor.
mkdir -m 700 /tmp/gnupg
gpg --batch --no-options --homedir /tmp/gnupg --import /input/ubuntu-signer.asc
gpg --batch --no-options --homedir /tmp/gnupg --no-auto-key-retrieve \
  --status-fd 1 --verify /input/ubuntu-zlib.dsc

# Node: official project keyring mounted read-only.
gpg --batch --no-options --homedir /tmp/gnupg --no-auto-key-retrieve \
  --no-default-keyring --keyring /input/node-pubring.kbx \
  --status-fd 1 --verify /input/node-SHASUMS256.txt.asc
```

The two altered-copy checks use the same options. Archive inspection uses
standard archive readers without installing or executing payloads. A selected
member extraction returned a child-process error; full extraction of the
inspected DEB data archive into a fresh temporary directory succeeded, and
subsequent byte comparisons passed. No failure was treated as success.
The temporary archive-inspection script also passes a scoped Bandit scan with
zero findings and zero analysis errors.
Independent read-only review reconciled the signatures, publisher attribution,
published payloads and both candidate layer chains with no findings. All 44
referenced raw files have verified hashes and sizes; local report links pass.

[Machine-readable evidence](TASK-13013.7.21-zlib-authentication.json) retains
the signer identities, artifact bindings, full raw-file hashes and source URLs.
Raw files and the scoped archive-inspection script are at
`/private/tmp/task-13013-7-zlib-auth.j3H30A`; earlier source archives remain at
the TASK-13013.7.20 paths. Temporary retention is not permanent release storage.
