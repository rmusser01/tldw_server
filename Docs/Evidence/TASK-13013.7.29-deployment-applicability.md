## Other assessed matches: no confirmed deployment issue

Hydra, Lightning and NeMo are absent from the retained base source export and
app/worker/audio SBOMs. Their six dependency-review advisories refer to optional
packages in the universal `uv.lock`. No whole-lock exemption was added:

- **Hydra:** a static optional NeMo path connects authenticated streaming input
  `parakeet_rnnt_model_name` to `from_pretrained`, archive YAML configuration and
  Hydra `_target_` instantiation. This is a concrete conditional input path.
  An installed, working optional deployment and its model-loading prerequisites
  were not established. It is not a confirmed deployed exploit.
- **Lightning:** the inspected pyannote workflow reaches checkpoint loading but
  uses a fixed repository-owned model identifier. No attacker-selected
  checkpoint was established for that workflow; custom workflows are outside
  this scoped conclusion.
- **NeMo:** published descriptions did not establish the exact CVE-specific
  unsafe callable in the current optional graph. Its helper's omission of
  `weights_only` is insufficient evidence: locked torch 2.13.0 defaults that
  call to `weights_only=True`. No model/checkpoint was executed.

The companion includes primary sources, tagged source hashes, application line
references and limits for these six records. Their seven dependency-review rows
(including NLTK) remain subject to the existing gate.
