## Package and source correction

The administrator bundle restore can preserve externally supplied database
pages for later application FTS queries. Existing logical-import protections
remain in place. This work updates the native library without changing the
restore API; it does not claim a reproduced native exploit or authentication
defect.

[Debian's CVE-2026-11822 record](https://security-tracker.debian.org/tracker/CVE-2026-11822)
and [CVE-2026-11824 record](https://security-tracker.debian.org/tracker/CVE-2026-11824)
identify `3.53.4-2` as fixed while Trixie's `3.46.1-7+deb13u1` remains affected.
[SQLite's advisory record](https://sqlite.org/cves.html) identifies the two IDs
as the same FTS5 defect, fixed upstream in 3.53.2. The retained primary-source
snapshots document the vendor basis for this update.
