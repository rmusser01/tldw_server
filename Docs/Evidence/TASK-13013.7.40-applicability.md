# TASK-13013.7.40: remaining caller checks and SQLite import correction

This continuation identified a reproducible SQLite import-validation defect
and established fourteen narrowly scoped advisory exclusions. Existing Chroma
and other approved exclusions are preserved. Scanner severity is retained as
reported; it is not presented as demonstrated application impact.

## SQLite import validation

An ordinary `PRAGMA table_list` can initialize an unrelated FTS5 virtual table.
Its configuration object can be a view that executes a MATCH query before the
importer checks whether its required tables are ordinary tables. Tiny, valid
databases reproduced this behavior on the candidate's SQLite 3.46.1. No malformed
pages, memory-corruption payload, model execution or exploit workload was used.

The first read-authorizer correction blocked a single configuration view.
Independent review found that nested FTS initialization can bypass authorizer
callbacks and execute a second configuration view. A built-in-only regression
observed an FTS index search, so the finding does not depend on a test-only SQL
function. The exact candidate reproduced that bypass too. The original
seven-case overlay results are retained as intermediate evidence, not final
qualification.

The correction disables trusted-schema execution on each importer-owned source
connection before metadata access and verifies that SQLite accepted the setting.
The persistent read authorizer additionally limits reads to the importer's
fixed tables and metadata. The generic table-list helper preserves existing
callers' authorizers. OpenWebUI hydration retains its built-in `json_each`
queries. Failures close the source connection and reject the import.

SQLite groups CVE-2026-11822 and CVE-2026-11824 as an FTS5 problem; the precrafted
database route requires malformed index data to reach MATCH processing.
Preventing the demonstrated import query path is an application correction,
not a claim that the installed SQLite library is patched. Administrator-selected
raw database restoration preserves database pages and later searches use MATCH.
That intentional privileged input path is assessed separately. Ordinary logical
record imports and server-created databases do not supply malformed index pages.
[SQLite advisory table](https://www.sqlite.org/cves.html),
[Debian 11822](https://security-tracker.debian.org/tracker/CVE-2026-11822),
[Debian 11824](https://security-tracker.debian.org/tracker/CVE-2026-11824).

## Explicit remaining limits

identifies parameter-entity handling in the internal DTD subset. Ordinary DOM
parsing still processes internal parameter entities without DTD validation.
librsvg rejects those declarations, and Python lxml embeds a later library,
but those facts do not clear the other OS DOM consumers. Two exact OS rows
remain gated; application exploitation is not confirmed. Further consumer
analysis intersects the existing restricted FFmpeg investigation.
