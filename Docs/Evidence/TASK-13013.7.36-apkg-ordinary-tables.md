# TASK-13013.7.36: validate Anki collection source tables

Anki imports now require `col`, `notes` and `cards` to be ordinary SQLite
tables before querying their contents. Before this change, harmless valid
APKG fixtures replacing each name with a view or FTS5 virtual table were all
accepted. The guard closes that confirmed source-validation gap.

Native `PRAGMA main.table_list` distinguishes ordinary tables from views,
virtual tables and their shadow tables. The existing DB-management schema
helper now owns this inspection and OpenWebUI reuses it. SQLite 3.37 or newer
is required; unavailable metadata fails closed with a clear import error.
Anki table-name matching remains case-insensitive, as SQLite SELECTs were
before this change. Ordinary, STRICT and WITHOUT ROWID tables remain valid.
No archive size, scheduling, media or note-count limits changed.

The first regression run failed ten checks: six view/virtual substitutions
were accepted, three missing-table errors lacked the new diagnostic, and one
case checked validation before imported-row reads. After implementation,
51 focused checks passed. Independent review identified a table-name casing
regression; six additional tests reproduced it, and the minimal comparison
fix resolved it. Final APKG/export/OpenWebUI schema checks pass **57 tests**;
the broader OpenWebUI adapter, service, hydration-helper and API suite passes
**63 tests**. These runs overlap on the schema suite and are not added together.
Independent re-review passes all 19 new schema checks, reports no remaining
actionable findings and confirms zero ML import attempts or loaded ML modules.

Ruff and new-test Black checks pass; changed production blocks conform to the
formatter. Existing unrelated Black drift in the two older modules remains
documented. AST parsing passes. Bandit reports zero production findings;
test-only assertions are recorded separately. The fixture's fixed test-name
SQL interpolation has scoped B608 annotations. Two initial exporter tests hit
the existing temporary-directory allowlist; they passed after using the
approved system temporary directory. No application path validation was weakened.

The [JSON companion](TASK-13013.7.36-apkg-ordinary-tables.json) records source

All six retained SQLite scanner rows remain gated. Their exact loaded native
