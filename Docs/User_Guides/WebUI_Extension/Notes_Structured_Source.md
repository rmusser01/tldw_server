# Notes structured source

The main Notes editor keeps the note body as exact source. Language is separate nullable metadata: Default means Markdown, explicit Plain text/Markdown/YAML/JSON/JSONL modes are available, and an unknown future value remains unchanged. Choosing a mode changes no source. YAML, JSON and JSONL use the installed native Monaco editor; other modes retain their existing source controls. Structured/future notes never invoke Markdown/WYSIWYG conversion, including while loading or restoring a device preference.

**Check document** checks the current whole source. Checks also run on initial open, mode changes and after 400 ms inactivity. Any edit immediately retires old diagnostics/success. Problems show logical line/column coordinates; selecting a Problem moves to the source. Background checks do not move focus or announce every keystroke. Check and explicit Format share 1 MiB UTF-8, depth 100, 100 diagnostic and 2 second processing bounds. Diagnostic status is separate from save/recovery status; syntax errors do not veto saving.

**Format document** is explicit and checks its own captured source. A changed proposal enters native history as one transaction; a no-op adds no history. Source edits, mode/authority changes, navigation, conflict, loss of editability and composition can retire a pending operation. Selection/caret and viewport are preserved. No source undo stack is stored by diagnostics, and manual/native changes retire the prior AI undo action. Pending Markdown attachment and Studio actions also check the current canonical document, authority, source and effective display language before writing; a later structured or temporary mode retires the old write.

LF and CRLF are supported without converting their representation. Monaco supports both an initial model-owned BOM and a leading FEFF pasted into its buffer; its adapter preserves the factual native prefix. YAML BOM formatting is qualified. The strict JSON/JSONL engines retain their BOM syntax refusal: those sources remain exact/editable/saveable, but format is blocked. Mixed LF/CRLF and lone CR are source-only native profiles; exact body, title and Save remain available. Ordinary textarea owners retain CR-bearing canonical source rather than passing it through a normalizing widget.

On a server proven unable to persist language metadata, a note whose canonical language field is proven absent may use a clearly labeled temporary display mode. Fresh implicit-default drafts can use the same session-only choice. It survives ordinary title/body save and benign same-note reload, but expires on note/authority/auth/connection changes or new canonical metadata. It is never claimed as portable metadata or automatically promoted. Missing capability fields alone are unknown. Known/null/future values and recovered explicit intent remain protected by normal save/ACK rules.

The Notes Dock opens structured/future server notes in main Notes before handing them to a mode-less local editor. Source-only profiles retain canonical text for title/save or offer that existing main open action. Secondary capture uses **Save source**: only exact text and the existing captured tag are saved; the displayed page URL is not persisted. The modal explains this before saving and keeps the URL visible. Existing older note bodies with inline source attribution are unchanged.

Monaco loads only local installed assets, prepared through existing postinstall/build/development entries. Next production/standalone serving consumes those prepared assets and does not require installed build dependencies. The shared loader restores the fixed native worker factory after the installed AMD initialization and before Notes, Presentation Studio HTML or Watchlists template editors use it. CSP, bundlers and the canonical Notes transport/storage rules are unchanged. Physical OS IME and system clipboard behavior remain unqualified by the synthetic composition and public native paste controls.
