# H2 workspace operation and candidate admission increment — 2026-09-23

The native store previously rejected every workspace-scoped asset candidate, while a closed workspace could still receive a fresh operation key or attempt generation. This Task 1.2 increment takes the workspace row lock after the operation row lock and requires an owned, ordinary, active, admission-open workspace before accepting a new key, generation, candidate, or prepared descriptor. A newly inserted key is removed if its workspace fails admission, even when the caller catches the conflict inside its transaction. Existing operation receipts remain resolvable under their original same-key rules.

The new SQLite tests failed before implementation. Open workspace candidates now reserve; closed, deleted and staged workspaces deny candidate reservation; closure between reservation and preparation denies the prepared transition; closure denies a fresh key or generation. Missing and foreign-owned workspaces also deny a fresh key, while a previously accepted key remains resolvable after closure. These cases run on SQLite and PostgreSQL. A PostgreSQL barrier holds candidate admission's workspace lock while deletion attempts closure, then verifies deletion waits and completes after admission releases its transaction.

The focused native transaction/workspace lifecycle/migration run passed **115 tests** with four inherited warnings; the later missing/foreign-owner matrix passed six cases across both engines. Ruff, compilation and diff check passed. Bandit found zero issues in 338 scanned production lines. Independent scoped review found no P1/P2; its suggested missing-workspace and same-key cases were subsequently added and passed.

This is the database admission boundary only. It does not verify or publish physical bytes, adopt candidates into child claims, commit a native child, or provide the final public fork flow. Candidates accepted before later closure remain durable for same-key reconciliation and cleanup; they cannot be marked prepared after closure.
