## Review Focus

1. **B2 stays as it is, by measurement.** The prototype moved `call_credential_source(...)` below `_build_adapter_request_from_chat_args` in both gateway functions, and read the built `request`. **It could not fail open.** `call_credential_source` reads three things, and here is each one in `kwargs` and in the built `request`:
   - **The handle.** The build puts into the request the same object that `bind_provider_call_credentials` authenticated (`gateway.py:887-888`).
   - **`base_url`.** It comes only from `_resolve_base_url_override`, which returns the `strip()`ped URL (`byok_helpers.py:318-330`).
   - **`api_base_url`.** It is a skip key (`:912`).

   **But it reorders every build error ahead of the 402.** That covers a `ChatConfigurationError` for a handle the runtime did not issue, a missing model or a missing key, as well as `validate_base_url_override`'s egress check. The wider set caught it: `test_messages_native_usage_recording.py::test_an_adapter_call_refused_at_the_call_after_an_own_key_admission_answers_402[json]` and `[stream]` got 502 instead of 402. Their fake runtime's handle is not runtime-issued, so the build raised before the check. Those tests pin TASK-13955's fix round: "a refusal at the call ... answers 402".

   The cleaner alternative would run the trust check before the quota check. That duplicates `_resolve_base_url_override`'s provider resolution and allowlist/trust branch, and validates the URL (an egress DNS lookup) twice. The finding itself fails closed: a 402 goes to an internal caller whose untrusted `base_url` the build would refuse anyway, and no such caller is reachable from `/chat/completions` (the schema rejects `base_url`) or the Messages API (the URL comes from `app_config`). So: no change. The reviewer should confirm that keeping the 402-first order is right.
2. **B1 makes one host stop counting: `api.openai.com.`** An absolute DNS name with one trailing dot is the same host, and httpx resolves it. Only the operator, a platform admin storing a key's base URL, or a trusted caller can set it. Two trailing dots still count, as does an empty label (`.api.openai.com`, `bedrock-runtime..amazonaws.com`). Those two did not count before, and they fail closed now. ADR-083's amendment ("a `*` ... matches one DNS label") already describes the new code, so no doc changes.
3. **R1: each file is indexed under both of its ids.** The alternative was a separate "`id:` differs from file name" error.
   - **What this approach catches.** A collision in either view fails CI, in backlog-py's (file names) and in the frontmatter's. That is exactly when the two tools disagree about which file holds an id.
   - **What it lets through.** A lone mismatched file with no collision passes. Neither tool finds a duplicate there, and its file-name id still blocks `task create`.
   - **Cost.** It is 3 changed lines, not a new error path.
   - **Measured.** 0 mismatches today, so dev stays green. Open PRs were not scanned (see "Not measured").
4. **R4: a file the check cannot read** still fails the step: it raises, so the exit code is 1 and the traceback stays. First it prints an `::error file=` annotation, so GitHub marks the file. Escaping follows `@actions/core`'s `toCommandValue`/`escapeData`/`escapeProperty`. The message escapes `%`, CR and LF; `file=` also escapes `:` and `,`.
5. **R7: `renumber_task(note=...)`** now takes a string or a sequence, like `edit_task(append_notes=...)`, and the CLI passes the tuple through. The generator's call with one string (`Helper_Scripts/renumber_duplicate_task_ids.py:598`) is unchanged. One edge changes: `note=""` used to be skipped and now appends an empty block, as `task edit --append-notes ""` already does. No caller passes `""`.
6. **B4 renames a test.** `test_a_provider_method_nested_in_an_own_key_stream_is_not_checked_again` becomes `test_a_provider_method_nested_in_a_stream_is_not_checked_again`, with 6 cases: layer `sync`, `async` or `awaitable`, times source `user` or `server_default`. It now records each check and the moment the body runs (a `"body"` marker), instead of relying on the `refused` fixture's 402, because a server-key stream must pass its own start check, and that check must come before the body. TASK-13959's ledger names the old test in mutation probe C; that probe's `-k nested_in_an_own_key_stream` becomes `-k nested_in_a_stream`.
7. **B6a's PostgreSQL test** builds its own `llm_usage_log` without the column in a schema of its own. It uses `unmanaged_authnz_pg_connection`, because the guarded pool refuses `DROP`. It then points a second `DatabasePool` at that schema through the DSN's `search_path`, and drops the schema in `finally`. That the sum is 1000 (not 0) shows that the shadow table was used: in `public` the row would be `user` and left out.

    """The same for a stream, whose body runs while it is read: an own-key stream is never checked, and a server-key
    stream is checked once, at its start, not again by a method nested in its body."""
    checks: list[Any] = []

    async def _admit(user_id: Any, requested_tokens: int = 1) -> None:
        """Admit everyone, noting each check."""
        checks.append(user_id)

    def _without_handle(request: dict[str, Any]) -> dict[str, Any]:
        """The request a delegate gets: no handle."""
        checks.append("body")  # called in the body, just before the nested call
        return {key: value for key, value in request.items() if key != PROVIDER_CALL_CREDENTIALS_CONTEXT_KEY}

    class _Delegating(_Provider):
        """stream() and astream() read their reply from chat() and achat()."""

        def stream(self, request: dict[str, Any], *, timeout: float | None = None) -> Iterable[str]:
            """Delegate to chat() while the stream is read."""
            yield self.chat(_without_handle(request))["choices"][0]["message"]["content"]

        async def astream(self, request: dict[str, Any], *, timeout: float | None = None) -> AsyncIterator[str]:
            """Delegate to achat() while the stream is read."""
            yield (await self.achat(_without_handle(request)))["choices"][0]["message"]["content"]

    class _AwaitedFirst(_Delegating):
        """astream() is a coroutine that returns the stream, as some adapters' is."""

        async def astream(self, request: dict[str, Any], *, timeout: float | None = None) -> AsyncIterator[str]:
            """Return the stream once awaited."""

            async def _items() -> AsyncIterator[str]:
                """Delegate to achat() while the stream is read."""
                yield (await self.achat(_without_handle(request)))["choices"][0]["message"]["content"]

            return _items()

    monkeypatch.setattr(llm_quota_gate, "llm_quota_refusal", _admit)
    request = {**REQUEST, PROVIDER_CALL_CREDENTIALS_CONTEXT_KEY: await _handle(source)}
    with llm_call_context(user_id=7, records_itself=True):

    """Escape a workflow command's message, or with ``prop`` a property such as ``file=``, as GitHub's toolkit does."""
    value = value.replace("%", "%25").replace("\r", "%0D").replace("\n", "%0A")

def _task_ids(path: Path) -> set[str]:
    """The id in the file's name and the one in its ``id:`` line; the same id unless the two disagree."""
