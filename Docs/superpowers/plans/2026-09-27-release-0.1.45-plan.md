## Why a release

`frontend-license-gate.yml` runs on `pull_request_target`, which executes the workflow file from the default branch (`main`). The gate fix merged to `dev` (#3029, #3032) therefore had no effect on PRs. A superseded or cancelled run kept posting `failure` on `frontend-license-policy/trusted/*` and blocking merges. It only takes effect on `main`.
