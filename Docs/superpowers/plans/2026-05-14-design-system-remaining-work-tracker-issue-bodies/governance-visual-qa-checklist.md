# Add Browser/WebUI/extension visual QA checklist

## Purpose

Reduce visual regressions by making Browser, WebUI, and extension verification repeatable across shared design-system surfaces.

## Scope

Included guard, doc, CI, or ownership decision:

- Define a visual QA checklist for shared surfaces across WebUI and extension contexts.
- Include expected verification evidence for migration PRs.
- Document when browser-observed screenshots or interaction checks are required.

## Non-Goals

- This track does not replace automated tests.
- This track does not migrate product-area baseline entries directly.
- This track does not create or update public GitHub state without human approval.

## Done Criteria

- Durable artifact exists and is linked from the epic.
- Verification or review path is documented.
- Follow-up migration tasks know how to use the artifact.
