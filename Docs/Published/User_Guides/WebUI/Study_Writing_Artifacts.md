# Study, Writing, And Artifacts

Use these pages when you want to study material, create reusable prompts, export/import chatbooks, write drafts, generate presentations, or produce structured artifacts.

## Pages And Feature Sets

| Page or feature | Surface/status | What it lets you do | Common uses |
| --- | --- | --- | --- |
| `/evaluations` | Advanced self-hosted | Configure and inspect evaluation workflows. | RAG evals, model quality checks, benchmark review. |
| `/flashcards` | WebUI, extension options, sidepanel | Create, import, export, and review flashcards. | Study decks, spaced review, quick sidepanel review. |
| `/quiz` | WebUI, extension options | Create, edit, take, and review quizzes. | Knowledge checks, generated study workflows. |
| `/prompts` | WebUI, extension options | Manage prompt library entries and prompt-studio tabs. | Prompt catalogs, prompt tests, prompt optimization. |
| `/prompt-studio` | Legacy alias | Redirects to the Prompt Studio tab in `/prompts`. | Old links and route compatibility. |
| `/chatbooks` | Advanced self-hosted | Import, export, and manage chatbooks. | Backups, OpenWebUI imports, portable conversation bundles. |
| `/chatbooks-playground` | Advanced self-hosted | Test chatbook features and content-type workflows. | Chatbook authoring and import/export review. |
| `/writing-playground` | Advanced self-hosted | Draft, transform, and organize writing with templates and themes. | Writing sessions, manuscript drafting, style experiments. |
| `/presentation-studio`, `/presentation-studio/new`, `/presentation-studio/[projectId]` | Advanced self-hosted | Create and edit presentation projects. | Slide generation, deck editing, export workflows. |
| `/data-tables` | Advanced self-hosted | Generate, edit, preview, save, and export data tables. | Structured extraction, tabular outputs, generated datasets. |
| `/kanban` | Advanced self-hosted | Manage boards, cards, lists, and task-like artifacts. | Lightweight planning, source-linked project boards. |
| `/repo2txt` | Advanced self-hosted | Convert repository content into text bundles. | LLM context preparation, code review packages. |
| `/content-review` | Advanced self-hosted | Review content drafts or queued generated work. | Editorial review, content safety, reattach source workflows. |

## Larger Systems

Study and artifact pages often sit downstream of media, notes, knowledge, or chat. Flashcards and quizzes can support study loops. Prompts and Prompt Studio improve repeated model interactions. Chatbooks preserve and move conversation data. Presentation Studio, data tables, writing, kanban, and repo2txt produce artifacts that users may export, share, or feed back into chat and knowledge workflows.
