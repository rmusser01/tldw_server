## Design and ADR assessment

ADR required: no new durable rule. [ADR-016](../ADR/016-acp-session-and-orchestration-persistence.md) governs existing owned session persistence/orchestration. Preserve raw RPC results and authored prompts, with actual observed native assistant text stored separately through existing service/DB APIs. No migration, new runner, protocol extension, configuration, dispatch retry, result wrapper or storage side channel.

The direct ActivePrompt owns native text fragments and an optional synchronous callback. Deliver joined text once after successful, noncancelled actual RPC settlement, before normal retirement. Do not invoke caller callbacks from the notification reader. The sandbox reuses existing client/task/Stop mechanisms with actual shielded settlement and source-client binding; an optional per-call timeout on ACPStreamClient matches existing stdio defaults/zero behavior. Every default caller remains compatible. Endpoint and Workflow are real persistence consumers; Scheduler remains a raw-result, nonpersisted consumer.

Canonical nested sessionUpdate kinds retain original raw params. Only exact text agent_message_chunk contributes assistant text; thought/user/tool/usage does not. Go checks actual downstream Session identity, and sandbox binds source client. Final RPC content takes precedence; never append both sources. Store/bootstrap readiness uses chosen text while raw_result remains exact. Native empty turns remain unavailable, without prior-turn reuse. UI parses native agent/user text and preserves legacy/diagnostic behavior.

Protocol v1 has no turn ID: post-settlement/no-active, foreign and cancelled updates can be isolated, but a protocol-violating old chunk after a successor starts is inherently indistinguishable. Do not claim an epoch guarantee absent from the protocol. Frozen wire/helper, metadata, permission and Queue units remain byte-preserved except necessary disjoint native hunks.

Production scope: thirteen paths: Go runner/connection; direct/sandbox/stream/stdio clients; ACP endpoint; session service/DB; Workflow ACP adapter; ChatPanel; ACP UI store; sessionMetrics. Retain exact pre-unit bytes only in memory; no proof or baseline files. The separate Go permission-session unit owns its registered-pointer guard refinement and qualification; this unit retains its prior native wire passes without replay.

The optional collector reuses the existing ACP_STREAM_BUFFER_MAX_BYTES (1 MiB) aggregate bound. Overflow refuses after actual RPC settlement, without callback or partial persistence. Capture is disabled for raw-result-only callers. Normally settled stopReason cancelled also suppresses captured text. Sandbox reader termination closes only its originating stream client so indefinite owned RPC waits settle on EOF/error.
