# Commercial text model defaults and availability

Provider documentation checked November 19, 2026. Output limits are tokens per request. Live discovery reflects account permissions and the configured endpoint. The bundled values apply when the request and operator config omit an output budget. A blank provider `*_max_tokens` setting selects that behavior.
