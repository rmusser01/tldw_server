**Context the issue text does not say:**
- Since 2026-10-11 (`466ab2ad54`, TASK-13573), ordinary sends in a saved server chat are settled by the server.
  - The client sends `saveToDb: true` with `tldw_history_selection_v1`; it does not use `clientManagedHistory`.
  - The server writes `model_id`, `provider`, `finish_reason`, `usage` and `generation_status` into `metadata_extra`.
  - Native Regenerate and Continue (`native-history-character-send.ts`) are server-settled too.
- Turns are still settled by the client in these cases:
  - Retry of a kept or failed turn (`retryAdmission`).
  - Edit and send through the pipeline (`historyEdit`).
  - Existing-selection regenerate.
  - Contexts that make `nativeCurrentInput` undefined: an actor rewrite, OCR, a `messageForModel` override, or system, error or reasoning rows in the history.
  - Servers without `native_completion_v1`.
- That remaining client-settled set is what "rest of CM-03" and "rest of CM-04" refer to.
