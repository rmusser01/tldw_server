## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Retained extension UAT showed the analysis dialog can display a valid persisted model while keeping Generate disabled because the large model metadata/catalog request is still pending. Trust the persisted selected model as an actionable fallback, while retaining catalog fallback and meaningful generation errors for stale selections.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Generate is enabled when media content and a non-empty persisted selected model are available, even before catalog loading completes.
- [ ] #2 When no persisted selection exists, Generate remains disabled until at least one catalog model is available.
- [ ] #3 The generated request uses the persisted selected model/provider identifier while the catalog is pending.
- [ ] #4 Focused unit coverage and the retained live extension analysis workflow pass.
- [ ] #5 A JSON-serialized persisted model is normalized before display, provider resolution, and chat request construction.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
First normalization iteration also wrote the corrected value back through useStorage. Live no-retry rerun showed the Generate button continuously re-rendering and never stabilizing for a click, so the repair write was removed. Normalization remains read-only at display/provider/request boundaries.
