## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Focused Tier 3 UAT reached teardown after a real ACP launch, then runLiveTierUat crashed in rmSync(profile.root) with ENOTEMPTY. This suppressed summary/report generation even though Playwright and services had completed. Identify lingering ACP runner ownership, terminate descendants deterministically, and make temporary-profile cleanup bounded and retry-safe without deleting outside the exact run root.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
