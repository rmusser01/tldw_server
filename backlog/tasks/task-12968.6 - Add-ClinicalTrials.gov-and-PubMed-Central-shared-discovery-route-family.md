## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implement the second credentialless route-family slice after the shared gateway foundation so the first Standalone Search cutover can prove at least twelve distinct ready targets. Use ClinicalTrials.gov API v2 for source-native trial discovery and NCBI Entrez E-utilities constrained to the PMC database for PubMed Central general-query discovery. Keep OAI/date feeds and identifier lookup represented as narrower route semantics rather than substitutes for general search. This task implements and fixture-certifies route/backend contracts in shadow mode; consumer-surface readiness is owned by TASK-12968.3 and TASK-12968.4.
