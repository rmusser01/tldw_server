## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950 (architecture review 2026-10-25). Finding H3, severity High, roadmap phase 2. Verified on dev dca11342de; roadmap: Docs/superpowers/plans/2026-10-25-architecture-remediation-roadmap.md.

There is no composition root for request-path services: endpoint bodies make 574 bare zero-arg get_x() calls (get_db_pool 69, get_acp_session_store 37, get_settings 31); there are 456 global statements in 231 files; 11 of 38 API_Deps modules hold module-level locks, caches or executors. api/v1/API_Deps/ChaCha_Notes_DB_Deps.py (1,030 lines) owns an executor, health map, shutdown lock and the per-user DB LRU cache (:52-82, :361) and is imported by 14 services and 4 core files, so background workers use the API layer as a registry; core/DB_Management/chacha/runtime.py:16 ChaChaRuntimeManager exists but only the deps module uses it. Tests compensate with 26,131 monkeypatch.setattr, 616 sys.modules writes, 288 reload() calls and 136 reset_*/clear_* helpers (27 used only by tests; reset_db_pool called in 155 test files) against 2,638 dependency_overrides assignments.
