## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Bring Python and Bun applications under deterministic vulnerability, update, SBOM, and artifact-provenance controls appropriate for a public release candidate.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 All shipped Next.js applications meet the approved supported security baseline and pass their regression suites.
- [ ] #2 Bun lockfiles participate in dependency updates and SBOM generation, and Python production resolution is reproducible.
- [ ] #3 Production base images and build artifacts use immutable provenance with vulnerability-scan evidence and an exception process.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Implement and test the fail-closed vulnerability exception policy.
2. Upgrade both Next.js apps and place Bun/uv/Docker updates under deterministic control.
3. Commit the universal uv resolution and use locked non-editable production syncs.
4. Replace source SBOM generation with pinned, validated, all-severity evidence and Critical/High policy evaluation.
5. Digest-pin five project images and six reference runtime images, including deployment preflight.
6. Implement release evidence assembly and OCI index/platform-manifest cross-checks.
7. Build once, scan exact candidates, promote three backend images only after the full gate, and make image/PyPI attestations explicit.
8. Publish operator documentation, run certification, complete review/rebase/PR/merge gates.
<!-- SECTION:PLAN:END -->
