## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The workbench can validate and submit v1 imports and queue backup exports. It shows the start response and job identity, while terminal status, retry details and the completed download currently require API status reads. Surface those outcomes in the interactive workflow with its existing job and account contracts.

## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Based on remote dev ca6f793617 with the first portability fix replayed as 192a459f1b. ADR-003 and ADR-094 govern Jobs ownership and durable domain receipts. This change uses those contracts without introducing a new architecture decision.

Verification passed for 96 backend portability tests, the VN OpenAPI contract test, the schema fingerprint and path checks, 36 focused WebUI and history tests, TypeScript, scoped ESLint and Ruff, and Bandit with zero findings. The broader WebUI run passed 395 tests and hit two legacy generation-recovery timeouts reproduced on the base. A disposable browser and live Jobs worker verified export download after reload, rejected a stale account header, replayed a lost import response to the same job, opened the restored pack, and recovered removal after a lost DELETE response. An earlier browser run exercised quota remediation and retry.

TASK-15667.1 tracks interrupted writes across storage and the import journal. A separate process crash before publishing a start receipt can leave a pending admission for follow-up.
<!-- SECTION:IMPLEMENTATION_NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
The VN assets workbench shows backup and restore outcomes, downloads finished backups, opens committed imports, and recovers admitted requests after reload with the original idempotency key. Quota retries share a key and require a journal that confirms no attempt began writing. Archive cleanup preserves an active restore and stays terminal on subsequent reads.
<!-- SECTION:FINAL_SUMMARY:END -->
