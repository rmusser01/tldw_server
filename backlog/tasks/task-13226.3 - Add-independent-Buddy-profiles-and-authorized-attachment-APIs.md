## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Allow users to keep Buddy artwork independently of a Persona and attach one Buddy to an owned conversation or workspace. Enforce workspace Persona defaults consistently during new conversation creation.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Buddy profiles own validated immutable artwork and attribution independently of the source Persona, with Static or Dynamic preference and optimistic versions.
- [x] #2 Authenticated APIs create, list, inspect, update, and remove profiles and manage a single client attachment without treating client IDs as authorization.
- [x] #3 Every target access is rechecked; cross-user, deleted, stale, and unavailable targets fail safely.
- [x] #4 Server conversation creation inherits workspace defaults only when assistant choice is omitted; explicit None and explicit overrides win and existing conversations remain unchanged.
- [x] #5 Authenticated starter preview asset content and image dimensions are available before copying a pack; attachment responses expose authorized target metadata and bounded conversation summaries.
- [x] #6 Attachment activity projects bounded latest persisted assistant results across authorized conversations with exact result acknowledgements that cannot clear a newer result.
- [x] #7 Selection-time conversation target resolution returns an authenticated owner-checked title and scope before attachment, including workspace conversations.
<!-- AC:END -->
