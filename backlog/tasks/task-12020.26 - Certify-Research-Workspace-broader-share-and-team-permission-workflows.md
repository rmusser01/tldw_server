## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
- Added owner-side share target validation in `sharing.py` so team shares require
  the current user's `team_ids` and org shares require `org_ids`; invalid targets
  now fail before repository insertion, preventing ghost shares to guessed scope IDs.
- Added Sharing endpoint coverage for valid owned org scope and invalid team/org
  scope rejection.
- Added Active Shares edit controls in the Research Workspace share dialog:
  native access-level select and clone checkbox now call the existing
  `useUpdateShare` mutation.
- Added ShareDialog coverage for active team/org share access and clone updates.
- Live backend validation used an isolated single-user server at
  `127.0.0.1:18061` with temp AuthNZ DB `/tmp/tldw_task12020_26_users.db`.
  Workspace upsert returned HTTP 200; invalid team target `999` returned
  HTTP 403 `You can only share with teams you belong to.`; invalid org target
  `999` returned HTTP 403 `You can only share with organizations you belong to.`;
  the active share list remained `{"shares":[],"total":0}` after both failures.
- Live WebUI validation used `127.0.0.1:3000` against the live backend. The
  share dialog rendered Team / Org, Share Link, and Active Shares tabs; screenshot
  `/tmp/tldw_task12020_26_share_dialog.png`.
- The active-share update path was validated with a seeded team fixture in the
  isolated AuthNZ DB because this single-user environment has no real team/org
  recipient membership fixture. The WebUI changed `Team #7` from `view_chat` to
  `view_chat_add`, enabled clone, received two HTTP 200 PATCH responses, and the
  DB row became `view_chat_add|1`; screenshot
  `/tmp/tldw_task12020_26_active_share_updated.png`.
- Observed follow-up: AntD warns that static `message` calls cannot consume the
  dynamic theme context. `ShareDialog` already uses static `message` broadly, so
  this is documented as a follow-up rather than expanded into this task.
- Observed fixture gap: true recipient-side behavior still needs a multi-user
  team/org membership fixture. This task certifies owner-side target validation
  and active-share controls, and records recipient-side validation as the remaining
  share coverage gap in the UAT matrix.
