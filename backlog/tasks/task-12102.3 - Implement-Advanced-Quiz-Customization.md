## Acceptance Criteria

- [ ] #1 Legacy quizzes and attempts remain readable and playable when advanced profile/subtype/group fields are absent.
- [ ] #2 Canonical profile IDs are standard_recall, mixed_assessment, best_of_five, emq, assertion_reasoning, and planned osce_scenario; subtype tags use best_of_five and assertion_reasoning.
