## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The MCP idempotency/category unit tests expect write-tool execution, but an ambient cached MCP configuration can disable writes before their calls; both isolated and full CI-mode local runs fail with write_tools_disabled instead of reaching idempotency assertions. Isolate the module default to enabled writes while retaining its explicit disabled-policy test.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
A standalone CI-mode module run reproduces two write_tools_disabled failures (13 passed); the earlier full MCP run had three analogous failures. The module fixture now sets writable default and clears cached config before and after each case. With ambient MCP_DISABLE_WRITE_TOOLS=true, all 15 cases pass including the explicit write-disabled control, zero skips. Current scoped Ruff clean; Bandit B101 LOW:41 and B110 LOW:1 unchanged from baseline. No production change. Full MCP and hosted gates remain.
