## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implement bioRxiv and medRxiv as the first credentialless route-family slice after the shared gateway foundation. The existing helper scans bounded recent/date API pages and filters locally, so it must not be represented as complete historical free-text search. General queries require a source-native site-search route or another certified source-constrained route with truthful attribution; the official API serves narrower interval, recent, category, and DOI capabilities. This task implements and fixture-certifies route/backend contracts in shadow mode; consumer-surface readiness is owned by TASK-12968.3 and TASK-12968.4.
<!-- SECTION:DESCRIPTION:END -->
