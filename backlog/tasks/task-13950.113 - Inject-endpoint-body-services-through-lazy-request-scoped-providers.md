## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950; follow-up of TASK-13950.20 (Ruling 2, re-handed from TASK-13950.18 ruling 1). Endpoint handlers call the container-backed getters get_db_pool() and get_jwt_service() inside their bodies. .20 kept them lazy and retargeted the 11 pairs, 50 patches (the plan's count) that patched the getter on an endpoint to the getter's home module (core.AuthNZ.database.get_db_pool, jwt_service.get_jwt_service). A plain Depends would resolve the pool before request validation (tests/Ingestion_Sources/test_ingestion_sources_api.py:151-223 asserts invalid input never fetches it) and build the JWT service before admin/admin_impersonation.py's 403 (:69 raises, :98 builds). The handler use-case extraction in TASK-13950.26 changes those signatures anyway, so this task moves the body getters to request-scoped providers that resolve lazily (after validation and authorization) and lets tests swap them with app.dependency_overrides or monkeypatch.setattr(app_services(), slot, fake).
<!-- SECTION:DESCRIPTION:END -->
