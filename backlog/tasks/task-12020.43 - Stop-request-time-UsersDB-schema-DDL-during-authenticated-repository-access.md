## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Live multi-user PostgreSQL UAT for TASK-12020.39 reproduced a 500 from notes search when concurrent workspace initialization requests each authenticated through AuthnzUsersRepo. AuthnzUsersRepo constructs a fresh UsersDB and runs users-table DDL on every lookup, allowing ordinary request concurrency to deadlock on PostgreSQL table locks. Move schema assurance back to startup/explicit initialization while preserving standalone UsersDB setup behavior.
<!-- SECTION:DESCRIPTION:END -->

<!-- AC:BEGIN -->

- [x] #2 Explicit standalone UsersDB initialization continues to ensure the users schema for SQLite and PostgreSQL callers.
- [x] #3 A focused regression test fails if repository user lookup invokes UsersDB schema creation.
- [x] #4 PostgreSQL concurrent authenticated lookup verification completes without deadlock-derived 500 responses.
- [x] #5 The TASK-12020.39 live Chrome CDP flow no longer records the notes-search 500.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Preserve explicit UsersDB schema assurance by default, add an explicit opt-out for repository adapters that receive the initialized shared DatabasePool, prove request-time lookups do not open DDL transactions, then verify concurrent PostgreSQL requests and the live Chrome CDP flow.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Implemented request-path/schema ownership separation. AuthnzUsersRepo now initializes UsersDB with ensure_schema=False against the ready shared pool; UsersDB tracks pool readiness separately from schema assurance so an opt-out may still be followed by explicit schema assurance. Removed SQLite schema inspection/DDL from create_user(), added idempotent AuthNZ migration 91 plus fresh-schema parity for every UsersDB write column, and corrected AuthnzUsersRepo.create_user() to use uuid_value and the returned user mapping. Review remediation also changed the PostgreSQL concurrency spy so it counts forbidden DDL calls without executing real DDL. Verification: mandatory red captured for missing migration 91; final combined suite 22 passed with TLDW_TEST_POSTGRES_REQUIRED=1, including concurrent PostgreSQL reads, SQLite repository writes, migration idempotence, JWT membership, RBAC migration-chain, and admin-webhook migration coverage. Ruff passed, compileall passed, Bandit reported 0 findings, and git diff --check passed.
