## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Built-in presets apply expected existing filters for Needs review, Failed ingest, Partially indexed, PDFs, Web captures, and Large files.
- [x] #2 Users can save the current source filter and sort state with a name.
- [x] #3 Reopening a saved view restores the filters and sort without inventing a new query language.

- [x] #5 Invalid or stale saved views fail soft and can be reset.
