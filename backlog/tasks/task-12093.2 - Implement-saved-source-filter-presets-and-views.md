## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implement child task 2 from the Paperless-inspired document lifecycle PRD: add built-in source filter presets and server-backed, user-saved source views over the existing Research Workspace source list state.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Built-in presets apply expected existing filters for Needs review, Failed ingest, Partially indexed, PDFs, Web captures, and Large files.
- [ ] #2 Users can save the current source filter and sort state with a name.
- [ ] #3 Reopening a saved view restores the filters and sort without inventing a new query language.
- [ ] #4 Saved views are isolated by user and workspace and restore after reload.
- [ ] #5 Invalid or stale saved views fail soft and can be reset.
- [ ] #6 Tests cover built-in presets, saved-view serialization, restore, isolation, and reset behavior.
<!-- AC:END -->
