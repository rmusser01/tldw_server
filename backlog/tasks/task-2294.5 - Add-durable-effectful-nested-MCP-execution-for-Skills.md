## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
After read-only nested execution is proven, design and implement durable effectful Skills execution with authorization revalidation, approval continuation, retry-safe idempotency, explicit partial-progress semantics, quotas, cancellation, and operator-visible run state. Use Jobs by default; any alternative durable runtime requires separate design approval and evidence of equivalent authorization, operations, and recovery properties. Never serialize provider credentials or treat an authorization snapshot as permanently valid.
