## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Implemented explicit hover/focus tooltip treatment for the main /chat cockpit Context and Runtime sidechannel controls. Added a local CockpitTooltipButton wrapper in apps/packages/ui/src/components/Option/Playground/PlaygroundCockpitShell.tsx and applied it only to the rail-local collapse buttons plus side-local restore handles. The handles remain anchored to the left/right rails; no bottom or composer collapsed summary was introduced. Added focused unit coverage in apps/packages/ui/src/components/Option/Playground/__tests__/Playground.cockpit-shell.test.tsx and real-server proof coverage in apps/tldw-frontend/e2e/workflows/chat-cockpit.real-server.spec.ts.

PR #1789 review follow-up: made CockpitTooltipButton tooltipId optional and generated by React.useId by default to avoid duplicate IDs when multiple cockpit shells render. Updated the real-server Playwright tooltip resolver to inspect every aria-describedby id and select the matching role=tooltip element by expected text, with a regression probe that prepends an extra non-tooltip described-by id.
<!-- SECTION:IMPLEMENTATION_NOTES:END -->
