## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Harden CloneService and the Workspace/Media repository boundaries so a clone is a coherent point-in-time snapshot, never mutates unrelated recipient media, and cannot expose partial targets as normal workspaces.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Source ChaChaNotes and Media reads use repeatable backend-native snapshots or fail closed before publication.
- [ ] #2 Share permission is revalidated before and during top-level copy work and before publication.
