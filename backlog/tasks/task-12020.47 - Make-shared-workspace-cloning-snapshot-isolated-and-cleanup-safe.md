## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Harden CloneService and the Workspace/Media repository boundaries so a clone is a coherent point-in-time snapshot, never mutates unrelated recipient media, and cannot expose partial targets as normal workspaces.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Source ChaChaNotes and Media reads use repeatable backend-native snapshots or fail closed before publication.
- [x] #2 Share permission is revalidated before and during top-level copy work and before publication.
- [x] #3 Explicit deterministic reserve/publish/discard methods replace the nonexistent CharactersRAGDB.create_workspace clone path and hide staged targets from recipient lists.
- [x] #4 An operation-owned Media snapshot insert never deduplicates against, touches, mutates, or appends transcripts to unrelated recipient media.
- [x] #5 Controlled failures clean operation-owned resources and bounded reconciliation handles stale staged/publication-pending targets after process interruption.
- [x] #6 Focused SQLite/PostgreSQL repository, CloneService, isolation, collision, cancellation, cleanup, Bandit, and shard-coverage verification passes.
<!-- AC:END -->
