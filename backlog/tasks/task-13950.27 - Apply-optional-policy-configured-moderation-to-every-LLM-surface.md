## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950 (architecture review 2026-10-25). Finding H5-mod, severity High, roadmap phase 3. Verified on dev dca11342de; roadmap: Docs/superpowers/plans/2026-10-25-architecture-remediation-roadmap.md.

Owner decision 2026-10-25: moderation applies to every LLM-calling surface but stays optional and policy-configured. Today moderation runs only in the /chat/completions path (chat_service.moderate_input_messages :3651, streaming output in execute_streaming_call, non-stream via moderation_pipeline.apply_output_safety_to_choices :86) and surfaces that call that route (persona live, writing playground). perform_chat_api_call(_async) (chat_service.py:2643-2742) applies none, and 53 files call or reference them. Unmoderated: the chat auto-router sends the latest user turn to an LLM (chat.py:3666) before the input check (:4517); /api/v1/messages (messages.py:2116,2143); character complete-v2 (:7439), roleplay resume and router; workflow LLM steps; RAG generation (generation.py:532); voice assistant (VoiceAssistant/router.py:1153); voice chat WS (speech_chat_service.py:815, docstring says it avoids moderation); study assistant and StudyPacks; Prompt Studio and media summarization (direct adapter calls); watchlists briefs; deep research; MCP quizzes; VN Play has its own unwired hook. Policy today: config.txt [Moderation] enabled = False, MODERATION_* env (config_sections/moderation.py), per-user overrides (/moderation/users/{id}); no per-surface or per-org scope.

Review and dry run (2026-10-25): Review: per-user overrides coalesce enabled (Moderation/policy_compiler.py:138) and Guardian forces enabled=True for supervised accounts (Moderation/supervised_policy.py:325), so a literal 'enabled=False disables everywhere' would switch off parental controls; AC3 keeps them.
