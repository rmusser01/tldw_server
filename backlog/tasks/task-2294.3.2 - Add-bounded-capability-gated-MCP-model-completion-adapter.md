## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add the narrow host-composed model completion port required by the MCP Skills runner. Bind one operator-configured provider/model pair, explicit server-authenticated user and active team/organization scope identity, authoritative membership and credential-precedence resolution, quota reservation/reconciliation, native async cancellation, provider-native output token bounds, pre-decode response-byte bounds, and one outbound request attempt with all server-controlled retries and fallbacks disabled.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The host-neutral port exposes immutable positive numeric user and optional active team/organization identity plus a fixed-format server-generated opaque execution ID, capability, bounded request, and normalized result contracts without credentials, client/request identifiers, request metadata, or mutable MCP RequestContext.
- [x] #2 The production adapter revalidates active-scope membership and relationships from authoritative AuthNZ state, follows user then active-team then active-organization then server credential precedence without guessing memberships, advances only on authoritative absence, uses the frozen server endpoint with base-URL override trust disabled, and fails closed on invalid/revoked/unavailable scope.
- [x] #3 User/team/organization/server credential-scope failures and request-content-dependent provider outcomes do not mutate the global module breaker; only shared adapter, identity/accounting-store, and fixed provider-transport failures with trusted shared provenance may select record-failure behavior.
- [x] #4 Only a certified native-async provider path with hard response-byte, output-token, tool-suppression, cancellation, and no-server-retry capabilities is healthy.
- [x] #5 Provider output normalization deterministically requires one non-empty textual choice, rejects tool calls, malformed Unicode and prohibited controls, normalizes only line endings, and enforces character/UTF-8 byte limits without truncation.
- [x] #6 A durable worst-case quota/cost reservation occurs before dispatch; pre-dispatch cancellation releases it, post-dispatch ambiguous outcomes retain it, and post-completion reconciliation failure returns the valid result with the conservative reservation intact rather than inducing a duplicate call.
- [x] #7 A provider child that misses the cancellation cleanup deadline remains lifecycle-owned with its late result discarded, retains ambiguous accounting, and makes adapter health fail closed until termination; no task is left unreferenced.
- [x] #8 At most one outbound provider request attempt occurs with no server-controlled retry, fallback, streaming, tools, or multiple choices.
- [x] #9 Focused provider, credential-precedence, active-scope authorization, quota, egress, cancellation, retained-child lifecycle, bounds, output-normalization, identity-minimization, breaker-scope isolation, lint, compile, and Bandit checks pass.
- [x] #10 Provider response limits are enforced over decompressed limit-plus-one bytes before JSON parsing; compressed expansion cannot bypass the cap.
- [x] #11 MCP authentication populates optional active team/organization fields outside generic request metadata; both fields are included in prepared-context integrity and second pre-dispatch verification, and single-user/no-active-scope calls preserve existing behavior.
<!-- AC:END -->
