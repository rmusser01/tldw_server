## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Design review findings incorporated in `Docs/superpowers/specs/2026-06-20-mcp-real-world-uat-smoke-design.md`: keep baseline unchanged, isolate artifacts, treat mounted artifact paths as same-host unless operators provide server-side templates, wire fixture server artifact roots through `MCP_SMOKE_ARTIFACT_ROOT`, and gate real LLM calls behind explicit provider/env options.

Implementation completed in branch `codex/mcp-uat-remediation-plan`:
added `real-world` scenario support, deterministic fixture artifact tools,
stdio fixture artifact support via `MCP_SMOKE_ARTIFACT_ROOT`, configurable
artifact tool names/argument templates, and an env-gated OpenAI-compatible LLM
step that reports only structural metadata.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Added real-world MCP UAT coverage with isolated artifact setup, read,
summarize, write, verification, prompt retrieval, and optional real LLM
provider calls. Baseline smoke behavior remains unchanged. Reports expose only
relative artifact paths, byte counts, hashes, and structural provider metadata;
absolute roots, raw artifact bodies, API keys, and full model output are kept
out of JSON summaries.
