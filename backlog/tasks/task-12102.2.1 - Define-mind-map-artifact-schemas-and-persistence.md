## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Versioned schema defines required map metadata plus stable node, edge, group, citation, and layout identifiers.
- [ ] #2 Validation rejects duplicate IDs, dangling edge/group/citation references, invalid roots, cycles where prohibited, and unsupported layout values.

- [ ] #6 Create/read/update and serialization round trips preserve topology, groups, citations, layout, and source metadata.
