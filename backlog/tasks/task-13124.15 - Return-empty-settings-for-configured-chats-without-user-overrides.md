## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Real-backend Chat-to-Notes UAT records four GET /api/v1/chats/{id}/settings?scope_type=global responses with HTTP 404 immediately after creating a chat. The backend intentionally treats absent or greetingsChecksum-only settings as not found, while the client treats that 404 as an empty settings record. The expected error response still creates repeated browser console failures and avoidable traffic during settings reconciliation.
<!-- SECTION:DESCRIPTION:END -->
