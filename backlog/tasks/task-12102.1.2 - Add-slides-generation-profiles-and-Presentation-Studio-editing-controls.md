## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Phase 2 for Slides and Infographics: wire source-backed generation profiles into existing Slides generation and add editor controls for mode, source bundle, visual blocks, citations, and per-slide regeneration.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Generation API accepts a supported profile and normalized source bundle and returns an artifact matching the selected mode contract.
- [ ] #2 Presentation Studio lists server-supported profiles and applies profile defaults without overwriting explicit user edits.
- [ ] #3 Selected media, notes, pasted text, page captures, and image references remain attributable through generation and editing.
- [ ] #4 Citation controls render source references and preserve them when text or visual blocks are edited.
- [ ] #5 Users can add, remove, reorder, and edit supported visual blocks with validation feedback.
- [ ] #6 Per-slide regeneration replaces only the targeted slide, preserves stable deck metadata, and reports source or generation failures without losing the prior slide.
<!-- AC:END -->
