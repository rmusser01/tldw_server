2026-08-25: Execution started from plan checkpoint 4ac00ec0cc. Root-cause evidence: prior probes showed webpack approximately 63 GB RSS and Turbopack approximately 22 GB RSS, but neither was measured under the approved identical full-route plus 20-minute idle plus second-pass guardrail. First cycle is pure evaluator TDD before process orchestration.

2026-08-25 webpack short probe (real isolated backend, 60s configured warm idle): initial route sweep 113/113 passed in 8.2m. Whole descendant-tree RSS: initial 5,663,014,912 bytes; post-traversal 38,668,189,696; post-idle 38,845,792,256. Second critical pass passed inventory only and timed out on Chat, Media, Knowledge, Notes, Prompts, and TLDW Settings (6/7 failed). Report: apps/tldw-frontend/test-results/dev-runtime/webpack-short.json. Classification: webpack fails RSS and second-pass responsiveness guardrails. The probe also revealed the shared polling helper could let one in-flight HTTP request exceed its deadline; added a red lifecycle test and a strict per-sample abort deadline in the harness before the Turbopack comparison.

2026-08-25 final comparison: the clean webpack short run completed 113/113 initial routes but reached 38,845,792,256 bytes RSS and failed 6/7 second-pass checks, so its irreversible guardrail breach was not held through a 20-minute idle. The clean Turbopack qualification completed 113/113 routes, all 40 warm-idle health probes over 20 minutes, and 7/7 second-pass routes. Turbopack peak RSS was 14,093,615,104 bytes and post-traversal-to-post-idle growth was 2,142,453,760 bytes, below the 16 GiB and 2 GiB guardrails. Reports: apps/tldw-frontend/test-results/dev-runtime/webpack-short.json and turbopack-20m-clean.json. Review hardening added clean .next removal, strict per-request readiness deadlines, whole-process-tree accounting, secret-safe env propagation, and immediate teardown on irreversible failure. Next 16.1.4 source confirms the red bottom-left numeral is Next DevTools total captured error count: not a tldw-owned counter, but still actionable evidence. Verification: 26 focused Vitest tests passed; touched-scope ESLint passed with no output; git diff --check passed. Frontend-only change, so Bandit is not applicable.
