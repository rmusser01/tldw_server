## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Implemented backend and frontend follow-on remediation for the Knowledge QA live RAG regressions. Backend changes enforce explicit source include scope before fallback retrieval, prevent Media DB fallbacks from broadening notes-only searches, retrieve explicitly selected notes by ID, exclude Knowledge QA self-history from chat evidence, skip answer generation when no documents are returned, and classify chunk/source-document citations as structural evidence. Frontend changes render citation markers visibly, auto-open evidence for cited answers even with fewer than three results, and fall back to standard RAG search when the streaming endpoint completes with no usable evidence. Focused backend and frontend tests pass after rebasing on latest origin/dev. The WebUI live browser gate is currently blocked by sandbox/approval usage limits when starting the local Next test server. The full UI package TypeScript check fails post-rebase in an unrelated Research Workspace test fixture where workspace_profile is optional but WorkspaceCapabilitiesResponse now requires it.
