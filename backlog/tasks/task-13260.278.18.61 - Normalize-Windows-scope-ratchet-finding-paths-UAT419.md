## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The tenant-predicate ratchet emits Path objects via implicit string formatting. On Windows this yields backslash paths while its committed baseline uses forward slashes, so exact-baseline CI reports false added/stale findings. Normalize only the emitted relative path representation.
