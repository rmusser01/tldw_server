Owner decision 2026-10-25: Scheduler folds into Jobs (the owner confirmed no fold work was in progress; a re-check of dev, open PRs and Docs found none). Recent owner-scoping work (TASK-13437, TASK-13864) makes watchlist and agent runs execute as their user, which the migration must preserve. PromptStudioDatabase.py:1516-1538 holds a third lease-queue API with no production caller. Related: TASK-13950.39 (wrappers, test collection), TASK-13644 (Scheduler migrate_schema stubs).
