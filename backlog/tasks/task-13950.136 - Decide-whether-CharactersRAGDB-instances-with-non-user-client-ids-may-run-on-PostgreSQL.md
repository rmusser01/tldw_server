## Description

Parent: TASK-13950.23 (close-out, 2026-11-22). Lines as of dev d0bc518192.

TASK-13950.23 made PostgreSQL owner scoping follow the instance's client_id: message-store locks derive it (#3547) and the generic helpers raise without an owner (#3548). Some code constructs CharactersRAGDB directly with a non-user client_id (workflow_engine, mcp_*, persona_memory_*, Notes_Library; find them with git grep -n 'CharactersRAGDB(' -- tldw_Server_API/app). On PostgreSQL those instances now see only rows whose client_id equals that service id. Decide per caller: bind to the acting user, or document the service id as a real tenant. Add a test for each path that runs on PostgreSQL.
