## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Characterize the current eight-source behavior, then introduce the versioned route model, a secure one-physical-hop policy-enforcing egress gateway, pure planning/normalization/budget transitions, and an injected V2 executor exercised offline against frozen fixtures and synthetic inputs. Preserve the legacy production path until TASK-12968.3 while proving that every adapter enabled in the V2 route registry uses the gateway and cannot dereference result URLs, read credentials, or fall back to legacy scraping.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Characterization tests freeze legacy omitted/empty/explicit/category selection semantics, ordering, source statuses, provider-call counts, errors, and serialized results for the existing catalog.
- [x] #2 Versioned source, route, backend, policy, attempt, and provenance contracts support multiple routes per source, coalesced backend requests, stable attempt IDs, an additive route-independent V2 document identity, and byte-compatible existing result/evidence identities.
- [x] #3 Every adapter enabled in the V2 route registry performs outbound I/O only through the injected one-physical-hop gateway; DNS/redirect policy, connect-to-validated-address and peer enforcement, trust_env isolation, streamed aggregate limits, policy revocation, and sanitized errors are tested, while the legacy compatibility adapters remain characterized but are not mislabeled as gateway-backed.
- [x] #4 Phase-one execution is metadata/snippet-only: returned URLs are inert and provider errors never invoke generic fetch, Media ingestion, Playwright, secret storage, CookieManager, or legacy scraping.
- [x] #5 The executor reserves and reports each physical hop, redirect, retry, route attempt, wall time, and result usage truthfully with a fresh dispatch ID before every request and typed empty, partial, skipped, timed-out, failed, and cancelled outcomes.
- [x] #6 The existing catalog produces golden-equivalent standalone behavior with the V2 executor disabled in production and exercised offline against frozen fixtures; no unconsented production double-fetch occurs, and focused tests, lint/format checks, Bandit, and diff hygiene pass.
