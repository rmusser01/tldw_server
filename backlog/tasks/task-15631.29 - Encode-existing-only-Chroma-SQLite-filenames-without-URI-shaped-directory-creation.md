## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Chroma1.5.9 performs filesystem parent-directory operations on its SQLite URL before SQLite parses it. A fully percent-encoded absolute native filename in file:... mode=rw makes that pre-open parent empty while SQLite still decodes once and enforces no-create. Preserve the existing supported Claims read contract and all guards; require actual Windows proof before acceptance.
<!-- SECTION:DESCRIPTION:END -->
