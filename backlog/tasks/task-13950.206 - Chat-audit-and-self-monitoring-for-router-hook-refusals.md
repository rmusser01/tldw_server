## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by the final review of TASK-13950.27 (Minor 4; owner choice, recommendation below). With the llm_router strategy the chat auto-router runs (chat.py:3782) before chat's own input moderation (:4635). A message chat would block is refused by the router hook instead, so no chat audit row is written and self-monitoring does not run, which undoes the mandatory-audit reason for keeping chat on its own pipeline. Recommendation: the router path writes chat's audit event (and runs self-monitoring) on LLMPolicyRefusal; the alternative is to run chat's input check before the router.
<!-- SECTION:DESCRIPTION:END -->
