## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950.23 (close-out, 2026-11-22). Lines as of dev d0bc518192.

Since TASK-13950.23 D1 (#3547), add_message on PostgreSQL locks the conversation with the instance owner, so the chat import endpoint (import_conversation) fails with 400 'Cannot add message: ... not found' when it imports for an owner other than the store's bound user. Production binds the store to the request user, so only mismatched setups hit it. Decide whether import should ever write for another owner; if not, reject it up front with a clear error, and pin the behaviour with a PostgreSQL test.
