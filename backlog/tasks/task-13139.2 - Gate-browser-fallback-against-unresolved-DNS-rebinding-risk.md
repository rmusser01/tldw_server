## Description

<!-- SECTION:DESCRIPTION:BEGIN -->

Add a fail-closed capability gate for untrusted and strict multi-user retrieval unless an approved pinned transport or governed proxy can attest the destination.

<!-- AC:BEGIN -->

- [ ] #3 Strict multi-user and untrusted retrieval profiles fail closed by disabling browser escalation unless a governed proxy or equivalent transport provides an approved destination-attestation contract.
