## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in TASK-13950.25 PR A. The order of keys in generation_metadata depends on the hash seed: sanitize_generation_metadata (core/Chat/generation_metadata.py:144) walks a frozenset of keys. The golden test therefore sorts that key's contents before comparing (tests/Chat/unit/test_chat_executors_golden.py:113-117). Build the dict in a fixed order at the source so the golden can stop sorting it.
