## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950 (architecture review 2026-10-25). Finding M-tuples, severity Medium, roadmap phase 4. Verified on dev dca11342de; roadmap: Docs/superpowers/plans/2026-10-25-architecture-remediation-roadmap.md.

Non-test app code has 4,732 handlers catching Exception and 7,715 catching *_NONCRITICAL_EXCEPTIONS tuples. Of 352 tuple definitions, 332 contain both AttributeError and TypeError and 156 contain AssertionError, so programming errors are swallowed as noncritical. tests/lint/test_noncritical_exception_tuples.py only bans BaseException-only members such as CancelledError (TASK-13295). Example consequence: TASK-13433 (billing tuple swallows asyncpg DataError).
<!-- SECTION:DESCRIPTION:END -->
