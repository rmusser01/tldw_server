## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Coverage-map the legacy 17-case real-server workflow suite against maintained Tier-1 through Tier-3 and dedicated live-server coverage. Delete redundant scenarios, move or retain unique critical behaviors in the smallest honest live gate, update current routes and contracts, and use deterministic provider readiness without silently masking failures. Success is preserved behavior coverage, not preserving a case count.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Every legacy case is coverage-mapped to maintained Tier-1–3 or dedicated live-server coverage before edits; redundant cases are deleted rather than repaired.
- [ ] #2 Unique critical behaviors are moved to maintained tiers or retained in the smallest dedicated live gate.
- [ ] #3 Provider helpers select only configured chat-capable models and the deterministic local test service is used for generation wiring.
- [ ] #4 Current first-run tours, routes, roles, labels, selectors, and cleanup API contracts are represented without partial-mutation skips or swallowed assertions.
- [ ] #5 All non-optional live cases pass and every remaining skip has a concrete pre-mutation capability reason; success does not depend on preserving 17 cases.
