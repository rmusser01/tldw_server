## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950.21 (found while planning it, 2026-11-08). api/v1/endpoints/notes.py:_attachment_cursor_secret (:865) signs attachment keyset cursors with core_settings JWT_SECRET_KEY. LazySettings falls back to the public default 'a_very_insecure_default_secret_key_for_dev_only' (core/config.py:977) when no JWT secret is set, so on such deployments anyone can forge a cursor. Severity is low: the cursor payload is HMAC-bound to the authenticated owner, dataset, note and state filter, and _decode_attachment_cursor rejects a mismatch, so a forged cursor only moves the 'after' position inside the caller's own query. TASK-13950.21 D1 item (f) makes LazySettings honour [AuthNZ] jwt_secret_key, which narrows the window but leaves the default fallback.
<!-- SECTION:DESCRIPTION:END -->
