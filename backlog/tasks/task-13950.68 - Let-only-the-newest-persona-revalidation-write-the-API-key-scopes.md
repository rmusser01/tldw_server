## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950 (architecture review 2026-10-25). Follow-up found during the PR #3351 merge review; roadmap: Docs/superpowers/plans/2026-10-25-architecture-remediation-roadmap.md.

Two persona WebSocket revalidations can finish out of order, so a check that started before a key's scopes were narrowed can restore the wider scopes until the next pass (15 s by default). Revocation is still caught, because a failing check closes the socket, and the race predates #3351. ws_credential_headers in core/AuthNZ/websocket_principal.py also infers the winning credential from token_type, which can be wrong only in test contexts.
