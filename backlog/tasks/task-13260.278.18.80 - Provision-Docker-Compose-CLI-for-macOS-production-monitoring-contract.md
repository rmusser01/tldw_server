## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Mac CI job 109241630357 lacks docker, so the existing security render contract fails before `docker compose config`. Homebrew officially supplies docker and docker-compose formulae, with Compose plugin under the Homebrew lib/docker/cli-plugins directory; the CI step installs both, links the plugin into the Docker CLI discovery directory, then checks version. The step is limited to macOS core-utils-tooling. CI YAML parses with the scoped condition and the exact Compose render contract passes on the local Mac (one pass). No Python production code changed, so Bandit is not applicable to this YAML-only task. Hosted macOS setup and contract remain open.
