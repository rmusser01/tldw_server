## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950 (architecture review 2026-10-25). Follow-up found during execution of TASK-13950.7 slices 1 and 2 (PRs #3333 and #3338); roadmap: Docs/superpowers/plans/2026-10-25-architecture-remediation-roadmap.md.

#3338 keeps a deprecated ACP-local shim so shipped clients keep working: useACPSession.tsx and services/acp/client.ts send ?token=/?api_key= to /acp/sessions/{id}/stream, prompt-studio-stream.ts sends them to /prompt-studio/ws, and ACPWorkspacePanel.tsx sends the x-api-key subprotocol. Every auth refusal happens before accept, which Uvicorn turns into an HTTP 403 that browsers report as 1006, so clients retry auth failures. The bearer-parsing ratchet lets an equal-count module swap through without a bump. Coordinate with TASK-12113 (tokens out of URLs).
<!-- SECTION:DESCRIPTION:END -->
