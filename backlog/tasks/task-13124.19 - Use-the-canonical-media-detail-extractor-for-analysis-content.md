## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Retained extension live UAT ingested and selected a real text item, but the Analysis modal kept Generate disabled. The media detail API returns direct string content while useMediaNavigationState only recognizes content when it is an object, duplicating and diverging from the canonical extractor. Route selected media detail through extractMediaDetailContent so analysis receives actual backend content across response shapes.
