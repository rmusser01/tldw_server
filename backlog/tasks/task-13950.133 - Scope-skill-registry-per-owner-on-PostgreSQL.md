## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950.23 (close-out, 2026-11-22). Lines as of dev d0bc518192.

skill_registry has no tenant column and its name/uuid are globally UNIQUE (ChaChaNotes_DB.py:3560, :28473), so on a shared PostgreSQL database one owner's skill names collide with another's and every owner sees every row. TASK-13950.23 D2 (#3548) opted its two version lookups out with OwnerScope.NOT_APPLICABLE because there is no client_id to filter on. Add a client_id column, make uniqueness per owner, add an RLS policy, then replace the two NOT_APPLICABLE opt-outs with the instance owner and lower the owner-scope baseline (tests/lint/owner_scope_baseline.json).
