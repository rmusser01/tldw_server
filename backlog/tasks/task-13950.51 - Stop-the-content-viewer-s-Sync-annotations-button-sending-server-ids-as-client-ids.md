The content viewer's "Sync annotations" action (apps/packages/ui/.../useContentViewerModals.tsx ~:681) posts existing annotations to /annotations/sync with their server ids as client_ids. Before #3324 every click duplicated every annotation; with client_id idempotency the first click still duplicates each annotation once, and later clicks are idempotent.
