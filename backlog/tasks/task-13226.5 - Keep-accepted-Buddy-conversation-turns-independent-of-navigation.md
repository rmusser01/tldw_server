## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Allow scoped Buddy replies to continue after the user changes pages or closes the interaction without bypassing existing Chat admission and authorization.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 An authenticated accepted-turn API owns bounded FIFO work independently of HTTP/WebSocket subscribers and exposes current status and exact result identity.
- [x] #2 Conversation and workspace membership are rechecked, and the existing Chat completion boundary retains its policy and provider admission.
- [x] #3 Stop and stale authority prevent late publication; idempotency keys do not dispatch duplicate turns; credentials are never persisted and uncertain interrupted work is not automatically retried.
- [x] #4 Focused tests cover route/transport detachment, two conversation queues, workspace scope, failure, stop, access loss and idempotence; runtime restart limitations are explicit.
