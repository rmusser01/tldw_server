## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Opening /research-workspace?shared={share_id} currently fetches shared metadata but leaves the normal local workspace sources/chat underneath it. Wire the recipient experience to canonical shared sources/media/chat endpoints and fail closed on invalid, revoked, or unauthorized shares.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Opening a valid share renders the shared workspace identity and shared source set, not the recipient's unrelated local workspace.
- [ ] #2 Read-only and chat permissions drive visible controls and requests; mutations outside the share access level are unavailable and rejected.
- [ ] #3 Recipient chat uses the canonical shared-workspace chat endpoint and cites only shared media.
- [ ] #4 Invalid, unauthorized, and revoked shares fail closed with scoped recovery copy and no local workspace data leakage.
- [ ] #5 Focused backend/frontend tests and live owner/member/non-member UAT cover the permission matrix.
<!-- AC:END -->
