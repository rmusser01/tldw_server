## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Export includes original PDF bytes, workspace saved Notes, generated content, citations, annotations and review metadata with honest missing-content errors
- [ ] #2 Offline archive provides human-readable reports and source files without requiring the original server
- [ ] #3 Import onto an isolated different server with colliding Media IDs restores editable workspace sources and remaps citation and review references to verified restored records
- [ ] #4 Malformed archives, partial import, stale authority and interrupted work cannot silently bind wrong sources or lose the original workspace
- [ ] #5 Roundtrip tests and real same-PDF cross-server walkthrough prove source checksums, Notes and citation navigation
- [ ] #6 Quickstart multipart uploads above10MiB reach the backend intact within an explicit128MiB request budget; oversized payloads reject413 before dispatch, counting legacy aliases and fields, and Chatbook imports preflight100MiB compressed.
