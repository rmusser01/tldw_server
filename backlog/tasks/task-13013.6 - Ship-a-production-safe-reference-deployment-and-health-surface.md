## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Replace unsafe production guidance with a reference profile that keeps stateful services private, requires non-default secrets, terminates TLS, and exposes only minimal public liveness while keeping detailed readiness and metrics operator-only.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The production profile does not publish PostgreSQL or Redis and contains no deployable default credential.
- [ ] #2 TLS, reverse-proxy trust, secrets, backup, and rollback requirements are validated by fail-closed preflight checks.
- [ ] #3 Public health returns minimal status while detailed readiness, provider state, database state, and metrics require trusted operator access.
<!-- AC:END -->
