## Description

Implement Chatbook dev routed fork_chat/new_chat behavior in tldw_server chat/agent ownership and both full-page clients. Resolve permitted provider/model or enabled preset before any child creation, persist the generation snapshot, expose selected target in the decision, and require each subagent request to obtain its own approval.
