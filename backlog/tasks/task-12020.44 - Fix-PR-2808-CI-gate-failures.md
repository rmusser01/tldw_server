## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
CDP inspection of the packaged extension confirmed the prompt-locale root cause: Vite expanded the guarded `import.meta.glob` call into a loader map but left the runtime `typeof import.meta.glob` condition false, so the browser selected an empty object. The direct top-level Vite glob is extension-only; the Next.js WebUI uses `apps/tldw-frontend/lib/i18n-web.ts`.

The retry fixture's deterministic review state was caused by the mock candidate introducing `{{topic}}` when the original draft had no template variable. The fixture now enables first-request failure explicitly and includes the same protected token in the original and candidate, preserving the production safety check.

Verification: focused i18n Vitest 5/5; extension compile passed; shard coverage reports `shards=775 test_files=4302 ignored=4 baseline=130 new_uncovered=0`; prompt packaged scenarios passed 12/12 in one strict run and the real-backend capability smoke passed separately against the CI-equivalent single-user fixture; Watchlists scenarios 1-12 passed in the final full attempt and scenarios 13-14 passed targeted after their final fixes; `git diff --check` is clean. No ESLint configuration exists for these packages, so the canonical TypeScript compile gate was used. Bandit is not applicable because no Python code changed.

The supported WebUI webpack production build (`bun run compile:prod`) compiled all 152 routes and passed shared-token synchronization, proving the shared extension i18n module is not parsed transitively by the Next/WebUI graph. The canonical Turbopack build could not run in this isolated worktree because `apps/tldw-frontend/node_modules` is a symlink outside Turbopack's filesystem root; it failed before application source parsing. Independent patch review found no actionable defects, and GraphQL reports zero unresolved inline review threads on PR #2808.

Final pre-commit rerun: shard coverage, focused i18n Vitest, extension compile, WebUI webpack production compile, and `git diff --check` passed. A fresh local Playwright rerun was attempted with three path variants but this worktree’s externally symlinked workspace dependencies caused Playwright to discover zero tests; the previously recorded successful E2E runs remain the local behavioral evidence, and the clean-install replacement CI run is authoritative.
