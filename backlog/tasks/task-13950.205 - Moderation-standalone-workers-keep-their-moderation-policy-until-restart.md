## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found by the final review of TASK-13950.27 (Minor 3). get_moderation_service() is a per-process singleton with no reload, so admin changes (per-user overrides, blocklist edits, PUT /moderation/settings, /reload) reach only the API process. Standalone workers (compose workers, Prompt Studio, media ingest, audio, data tables, explainer, research) keep the policy from their first call until restart. Documented in Moderation-Guardrails.md; add a reload.
