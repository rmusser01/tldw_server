## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Mounted WebSocket compatibility tests were leaving singleton MCP server state
behind by assigning `server.initialized`, `server.protocol`,
`server.auth_provider`, and several config fields directly. The leakage made
later mounted HTTP/batch tests order-dependent, returning the recording
WebSocket protocol stub instead of the normal protocol implementation.

Changed `_install_mounted_ws_single_user_compat()` to set those fields with
`monkeypatch.setattr(...)`, so pytest restores the singleton and config after
each test.
