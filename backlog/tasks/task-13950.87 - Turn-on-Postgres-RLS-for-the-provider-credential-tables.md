## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950 (architecture review 2026-10-25). Follow-up found during TASK-13950.17 PR A1's review (#3379); roadmap: Docs/superpowers/plans/2026-10-25-architecture-remediation-roadmap.md.

The five provider-credential tables (user_provider_secrets, org_provider_secrets, llm_provider_overrides, byok_oauth_state, byok_validation_runs) have RLS disabled and no policies on Postgres. Isolation rests only on the repositories' user and scope predicates, which A1's scope tests pin. RLS would add defense in depth for BYOK secrets. A1's test_provider_credential_tables_keep_their_rls_posture_postgres pins the current 'RLS off, no policy' state and must change with this task. Proving the policies needs TASK-13950.82's non-superuser test role.
