## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Fix the three validated Jobs admission defects: secret reject mode currently persists secret-bearing payloads, optional PostgreSQL counter errors poison the surrounding transaction, and concurrent quota checks can oversubscribe max-queued limits. Preserve the JobManager facade and current API behavior outside those defects.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Secret reject mode raises before insertion; redact and scanner-error fallback remain explicitly tested.
- [ ] #2 Optional PostgreSQL counter failures are isolated by a savepoint and do not abort job/event commit.
- [ ] #3 Quota query failures fail closed and roll back admission on SQLite and PostgreSQL.
- [ ] #4 Enabled owner/domain admission quotas are atomic under deterministic concurrency; PostgreSQL unrelated scopes remain independent and SQLite quota-disabled admission retains the deferred transaction path.
- [ ] #5 Focused SQLite and real PostgreSQL matrices pass with no PostgreSQL skips, and Bandit reports no new findings.
<!-- AC:END -->
