## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Fix the three validated Jobs admission defects: secret reject mode currently persists secret-bearing payloads, optional PostgreSQL counter errors poison the surrounding transaction, and concurrent quota checks can oversubscribe max-queued limits. Preserve the JobManager facade and current API behavior outside those defects.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Secret reject mode raises before insertion; redact and scanner-error fallback remain explicitly tested.
- [x] #2 Optional PostgreSQL counter failures are isolated by a savepoint and do not abort job/event commit.
- [x] #3 Quota query failures fail closed and roll back admission on SQLite and PostgreSQL.
- [x] #4 Enabled owner/domain admission quotas are atomic under deterministic concurrency; PostgreSQL unrelated scopes remain independent and SQLite quota-disabled admission retains the deferred transaction path.
- [x] #5 Focused SQLite and real PostgreSQL matrices pass with no PostgreSQL skips, and Bandit reports no new findings.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Hardened Jobs admission without changing the JobManager public facade: secret rejection now fails before persistence, optional PostgreSQL counter failures are savepoint-isolated, quota reads fail closed, and enabled owner/domain quotas are serialized atomically on SQLite and PostgreSQL. PostgreSQL idempotent admission now resolves conflicts through a bounded insert-or-lock loop: existing rows stay locked through replay-event commit, while a conflict deleted before the locking fetch is retried as a valid fresh admission instead of producing a stale response or invalid event. Optional psycopg absence produces an explicit dependency error. Added deterministic SQLite/PostgreSQL coverage for quota races, both replay/prune interleavings, independent owner scopes, transaction recovery, no-quota fast paths, and optional-dependency failure behavior. The implementation is rebased on origin/dev 1b9518c68c and locally verified with 72 focused tests plus security/static gates; final PR checks and the requester-authored Change summary remain merge gates.
