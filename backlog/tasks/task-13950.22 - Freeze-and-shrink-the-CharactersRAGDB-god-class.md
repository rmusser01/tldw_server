CharactersRAGDB (ChaChaNotes_DB.py:909-47351, 46,443 lines, 859 methods) owns notes, chats, characters, flashcards/quizzes, workspaces, moodboards, personas, sync, 150 distinct tables, 113 _migrate_* methods and connection/transaction handling. The chacha/ split (35 modules, 21 stores, 43,678 lines) does not shrink it: stores are built as Store(self), reach 61 private members 402 times, and 302 store methods are re-attached by setattr (:47354-47792) with 85 TYPE_CHECKING stubs (:934-1325), so the public surface never shrinks. Media DB uses a third mechanism (322 class attributes bound to module functions, media_db/media_database_impl.py:1963+). Open PR #3299 edits ChaChaNotes_DB.py and three stores (conflict risk). Prior split plan: Docs/Plans/2026-03-02-db-megafile-repository-split-implementation-plan.md.
