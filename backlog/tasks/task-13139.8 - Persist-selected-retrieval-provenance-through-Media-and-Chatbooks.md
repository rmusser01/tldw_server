## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Carry a selected safe retrieval envelope through the existing Media ingestion chokepoint and export it through the existing Chatbook v1.1 source_refs/provenance surface. Media is the sole durable web snapshot owner; MCP, Research, and Chatbooks do not create another persistence service, content type, or queue.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Before execution, the task adds the concrete Phase 2B implementation task produced by TASK-12964 as a dependency; this task does not implement that handoff itself.
- [ ] #2 Media persists extracted content and a bounded immutable retrieval-provenance record using existing metadata/versioning seams, with raw HTML, cookies, authorization, and credential-bearing headers excluded.
- [ ] #3 The persisted record includes safe source/final URLs, retrieval time, content fingerprint, selected validators, extraction/quality algorithm versions, tier trace, and source-provider identifiers when supplied.
- [ ] #4 Chatbook export maps Media-owned provenance into existing source_refs or compatible metadata without adding a new Chatbook content type or silently changing v1.1 import compatibility.
- [ ] #5 Re-import preserves safe provenance and content identity where the current format permits; unsupported optional fields degrade additively rather than failing legacy imports.
- [ ] #6 Owner isolation, duplicate Media records, changed snapshots, export/import round trips, redaction, and backward compatibility are covered by focused and E2E tests.
<!-- AC:END -->
