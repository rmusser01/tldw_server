## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define the smallest shared offline fixture contract and baseline runner needed to measure current web extraction, agent-output efficiency, search ordering, crawl budgets, and provenance fields. Record current-dev behavior before later tasks introduce thresholds. Fuzzing, soak infrastructure, and feature-specific regression suites remain outside this task.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A versioned offline fixture schema covers representative HTML extraction, ordered search results, crawl link graphs, and retrieval provenance without public network access.
- [ ] #2 A fast deterministic runner records the current-dev baseline and reports stable machine-readable results plus a concise human summary.
- [ ] #3 Metrics use characters and UTF-8 bytes as primary output budgets; token counts are clearly labeled estimates and add no tokenizer dependency.
- [ ] #4 Extraction-quality and scoring calculations carry explicit algorithm versions so later result changes are attributable.
- [ ] #5 The task adds only shared fixture/runner coverage; each feature task owns its behavior tests, while fuzz and soak work remains parked.
