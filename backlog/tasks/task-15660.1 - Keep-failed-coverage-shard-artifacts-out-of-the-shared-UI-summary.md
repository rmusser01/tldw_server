## Implementation Notes

<!-- SECTION:IMPLEMENTATION_NOTES:BEGIN -->
Follow-up to TASK-15660. PR 3640 attempt 2 fetched artifact 15159530470 instead of passing artifact 15159093127. PR 3641 has the same failure on shard 28.
Attempt 3 selected the same stale artifact. The pinned download action selects the largest numeric id per artifact name. The workflow now names blobs by the coverage test step outcome, keeping failed diagnostics out of the existing passing-shard download pattern. The report still requires 32 nonempty blobs.
Verified red on the original workflow, then 378 CI contract tests passed. actionlint 1.7.12, Ruff, compileall and git diff --check passed. Bandit recorded the same 67 existing B101 test assertions before and after with no other findings. No ADR or user documentation change is needed because merge-gate policy and report completeness are unchanged.
