Core workers import this endpoint module (Embeddings/services/jobs_worker.py, Evaluations embeddings_abtest_*).

Review and dry run (2026-10-25): Ordering: the provider-not-supported 4xx slice can land at any time; the core-import acceptance criterion coordinates with TASK-13950.20.
