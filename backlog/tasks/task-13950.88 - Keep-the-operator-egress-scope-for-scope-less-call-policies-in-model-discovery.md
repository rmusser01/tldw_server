## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Parent: TASK-13950 (architecture review 2026-10-25). Follow-up found during Phase 1 CI review of the Frontend E2E Tiers runs; roadmap: Docs/superpowers/plans/2026-10-25-architecture-remediation-roadmap.md.

#3191 (TASK-13460, merged via #3353 on 2026-10-27) broke three character-chat journeys in the Frontend E2E Tiers workflow on every PR since. The roleplay-resume path of complete-v2 passes a capability-only ProviderCallPolicy (no required_endpoint_scope). Model discovery let any policy replace the operator's server-owned egress scope, so the strict default egress policy refused the server-configured loopback base before any request; discovery reported 'unreachable' and complete-v2 returned 500 provider_model_inventory_unavailable. Generation treats the same policy as non-strict. Prompt improvement, the flashcards study assistant, direct-adapter callers and the Anthropic/HF alias lookups pass the same kind of policy.
<!-- SECTION:DESCRIPTION:END -->
