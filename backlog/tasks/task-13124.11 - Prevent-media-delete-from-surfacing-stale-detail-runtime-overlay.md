## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Live real-backend UAT reproduced the user's red issue badge and error popup. After deleting the currently selected media item, the WebUI requests GET /api/v1/media/{id}; the backend correctly returns not found/inactive for the trashed item, but background-proxy throws into the Next.js runtime overlay, which blocks the Trash control.
